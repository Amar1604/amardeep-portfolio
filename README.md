A high-performance, dark/light mode developer portfolio website built using **React 19**, **Vite**, and modern component-driven architecture. Designed to showcase full-stack engineering, cross-platform mobile development (Flutter/Dart), AI/LLM tools, and hackathon achievements.

---

## 🌟 Key Highlights & Features

- ⚡ **React 19 + Vite**: Ultra-fast build times, zero-latency Hot Module Replacement (HMR).
- 🌓 **Dynamic Theme Switcher**: Glassmorphic dark/light mode toggle synchronized with `localStorage`.
- 🌌 **Interactive Particle Canvas**: Physics-based interactive particle network with mouse repulsion and adaptive density.
- 🎴 **3D Interactive Tilt Cards**: Smooth perspective micro-interactions on hover.
- 💰 **BudgetBuddy Flagship Showcase**: Highlights the Infosys Springboard Capstone project with deep-dive modal inspection.
- 📱 **Mobile Development Specialization**: Dedicated Flutter & Dart toolkit showcase.
- 📄 **Recruiter Quick-Scan & ATS Resume Download**: One-click verified resume download.
- 📱 **Fully Responsive**: Mobile-first fluid layout across all screen sizes.

---

## 🛠️ Tech Stack

- **Frontend Core**: React 19, JavaScript (ES6+), HTML5, CSS3 Custom Properties
- **Icons & UI**: Lucide React, Glassmorphism, CSS 3D Transforms
- **Bundler & Tooling**: Vite, ESLint
- **Data Layer**: Centralized JavaScript data stores (`projectsData.js`, `portfolioData.js`)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Amar1604/amardeep-portfolio.git
cd amardeep-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
